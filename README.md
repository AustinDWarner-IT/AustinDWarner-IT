- **Two production AI systems** on a shared frontend (**ClaimAI**) — a fine-tuned Hugging Face NLP model that flags medical billing discrepancies (LangChain + Chroma RAG, OCR + document generation for provider letters), and an internal company chatbot on **Azure AI Foundry** (Azure OpenAI, AI Search, Prompt Flow). Serving 30 internal users.
- Architected and shipped a full **EDI SaaS platform** on AWS — 837/835 processing, auth, RBAC, HIPAA compliance, dev → staging → prod CI/CD.
- Rebuilt a legacy claims-audit workflow (**Logic-on-the-Fly**) from a broken ~4-hour process to **under 10 minutes**.
- Built **multi-cloud GitHub Actions pipelines** deploying to EC2, S3, RDS, App Service, AKS, and Azure SQL across dev/staging/prod.
- Deep hands-on with **SQL Server, PostgreSQL, and Redis** — stored procedures, indexing strategy, CDC, lock-contention debugging.
- Designed **multi-cloud network architecture** — VPCs, VNets, WAFs, ALB/NLB, Azure Front Door, EKS/AKS containers.
